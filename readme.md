# IA Fácil - Portal de Serviços Digitais

Projeto desenvolvido na disciplina de Programação Web (Professora Sandra Mara Cisz),
como parte da Entrega 1 - Aulas 1 a 6.

## Sobre o projeto

O **IA Fácil** é um guia digital voltado para pessoas que querem aprender a usar
melhor as ferramentas de Inteligência Artificial no dia a dia. O portal apresenta
conceitos básicos de IA, mostra categorias de ferramentas disponíveis e oferece um
canal de contato para dúvidas e sugestões.

## Páginas

- **Início (`index.html`)**: apresentação do projeto, o que o visitante encontra
  no portal e uma dica de como escrever bons prompts para ferramentas de IA.
- **Ferramentas (`servicos.html`)**: categorias de ferramentas de IA (assistentes,
  criação de imagens, textos/produtividade e programação).
- **Contato (`contato.html`)**: formulário para dúvidas, sugestões ou pedidos de
  orientação sobre IA.

## Observação sobre o formulário

Até a Aula 6 o projeto trabalha apenas o Front-End. O formulário valida os campos
pelo navegador, mas ainda não envia os dados para um servidor - isso dependerá de
um Back-End ou serviço externo, que será visto em aulas futuras.
